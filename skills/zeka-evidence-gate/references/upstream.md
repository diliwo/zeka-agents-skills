# Upstream inspiration

Conceptual reference: Michael Shimeles' [evidence-driven-testing](https://github.com/michaelshimeles/skills/tree/main/evidence-driven-testing),
particularly its [SKILL.md](https://github.com/michaelshimeles/skills/blob/main/evidence-driven-testing/SKILL.md),
reviewed on 2026-09-20.

Retained concepts: revision stamping, explicit test targets, passed/failed/untested
outcomes, before/after observations, caveats and evidence artifacts complementing CI.

Zeka adaptations: behavior-first backend evidence, typed manifests and source metadata,
required-target coverage, separate focused/regression/protected CI levels, blocked
outcomes, strict SHA binding, safe local artifacts and a review-loop adapter. Video,
posting evidence and browser tooling are not mandatory or automatically authorized.

Implementation and instructional text here are original. No upstream code or
substantial instructional material was copied. The upstream root LICENSE lookup did
not establish a license for code reuse. If future changes reuse upstream material,
verify the applicable license first and preserve required notices and attribution.
